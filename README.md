# 😴 Sleep, Screen Time & Sleep Debt Analysis — Power BI

## 📌 Overview
A data-driven Power BI dashboard examining the impact of daily screen time on overall sleep duration, sleep quality, and cumulative sleep debt across various user segments.

## 📸 Dashboard Preview
![Sleep Dashboard](sleep%20debt%20dashboard%20ss.png)

## 🛠️ Tools Used
* **Business Intelligence:** Power BI Desktop
* **Data Analytics:** Power Query, DAX formulas for calculated metrics (e.g., Sleep Debt = Recommended Sleep - Actual Sleep)

## 📊 Key Findings
* **Screen Time Impact:** Direct correlation between late-night device usage and reduced total sleep hours.
* **Sleep Debt Trends:** Tracking weekly accumulation of sleep deficit and recovery patterns across age groups.
* **Optimal Balance:** Key visual insights highlighting daily screen time thresholds to maintain healthy sleep schedules.
